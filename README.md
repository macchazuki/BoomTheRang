# BoomTheRang

A Three.js web game built with Vite.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run build
```

Pull requests automatically run the test and production build checks. Successful pushes to `main` deploy the production build to GitHub Pages.

## One-time GitHub Pages setup

In the repository settings, open **Pages**, set **Source** to **GitHub Actions**, and save. The deployment workflow will then publish the site after the next successful push to `main`.
